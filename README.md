MuaxkyOS
========

What is this?
-------------
MuaxkyOS is a personal project of mine mainly for x86 assembly training purpose. The goal of this project is the creation of a basic operating system for 8088-based computers such as the IBM 5150 PC.

Planned Features
----------------
- Bootloader
- Custom File System
- Hard Drive Support
- Command Line Interface
- Code/Text Editor

When will it be completed?
--------------------------
Progress on development is probably going to move very slow as I'm only going to work on it sometimes in my freetime.
